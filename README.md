# Al-Ala Education Foundation — Welfare & Education Website

> A multi-page public information and donation website for the Al-Ala Education Foundation welfare wing.

## Technology

- **Web:** HTML, CSS, JavaScript, with a Vite/React prototype in `src/`
- **Tooling:** Node.js, npm, Vite, TypeScript
- **Hosting:** [Vercel deployment](https://alala-foundation.vercel.app)

## Context

The site brings the foundation's programs, impact stories, giving information, and contact details together in one place for families and supporters.

## Features and implementation

- Separate pages for the foundation, programs, impact, Zakat, donations, and contact information.
- Donation and Zakat information, including an interactive calculator.
- Responsive layouts and client-side interactions implemented in the static HTML/CSS/JavaScript pages.
- The repository also contains a React/Vite entry point; the multi-page HTML site is the primary published experience.

## Run locally

```bash
npm install
npm run dev
```

Use `npm run build` to create a production build. Static pages can also be opened directly in a browser.

## Scope and validation

This repository documents and presents the website; it does not include verified donation-processing or visitor-impact analytics. No measured impact or performance metrics are claimed.
